# Agent Note: 被拒绝的运行正是审计轨迹的用途所在

Status: implemented

[English](2026-09-03-run-admission-audits-every-outcome.md) | 中文

## Problem

[R3 的第四条](../../proposed/architecture/2026-09-02-multi-tenant-cli-agent-runtime.zh.md)要求一条按租户划分的审计轨迹。在寻找它该挂在哪里的过程中，先翻出了一个更小、也更糟的问题。

`admitRun` 只在运行被准入时返回保险库的审计记录。每一种拒绝都只返回一个 rejection，别的什么也没有。而 `openCredential` 在其*失败*分支上与成功分支上一样会返回 `CredentialAuditEvent` —— `CredentialOpenResult` 的两个变体都携带 `audit` —— 本模块却把失败的那条丢掉了。被丢掉的正是保险库刚刚检测到的跨租户访问尝试：`binding-mismatch` 是一个租户的运行去够另一个租户的凭据，而 `corrupt` 是一个其认证数据与标签不符的信封。两者都被检测到、被记录下来，然后被扔掉。

值得记下来的是：这道缺口并非无人注意。包的 README 点名了它 —— 「拒绝时不返回任何审计记录」—— 而包的 Agent Note 在备选方案里列了审计 sink，并把这处省略称作一条限制。它被写成了设计的边界，而不是被读成设计里的缺陷。真正把它翻过来的，是去问审计轨迹究竟*为什么*存在：被准入的那一半才是无趣的那一半。

## Decision

`RunAdmission` 的每一个变体都携带 `audits`，并且由类型让这一点无法回避而不是可选。抵达了保险库的拒绝携带保险库对该次拒绝的记录；从未抵达保险库的拒绝携带空数组。

空数组是有意为之，而不是占位符。本运行时不予准入的令牌、已用掉的 nonce、以及没有存储凭据的账户，都在任何凭据被触碰之前就被拒绝，因此保险库什么也没产生；在这里造出一条记录，就等于本模块为一次从未发生的操作伪造审计条目。它转而做的事被写进了文档：需要记录这些拒绝的调用方去记录那个 rejection，而返回值已经按阶段为它命名。

`AdmittedRun.credentialAudit` 被移除了。在两个分支上都有 `audits` 之后，它成了同一个事实的第二个家，而两者可能漂移。

成功记录与失败记录形状相同，因为它们本来就是同一个形状 —— 保险库的 `CredentialAuditEvent`，未经改动。有一个测试断言被准入与被拒绝两种运行的键集合一致，因此一份按租户分区的存储能同时接纳两者，运维人员查询某个租户的历史时不必去拼接两套词汇。

## Consequences

跨租户凭据尝试现在可被报告。这正是全部要点，而且它是被检验过的、而非被声称的：把那一行修复回退，会有四个测试失败，其中三个点名具体的保险库拒绝（`binding-mismatch`、`revoked`、`corrupt`），另一个点名共享的记录形状。

这里仍然不持久化任何东西，这一点没有变。本模块返回记录；[边界页面](../../../../docs/candy-runtime-boundaries.zh.md)所要求的按租户分区存储仍归调用方，并且不提供任何顺序、保留或写入保证。

审计面依然只有保险库操作那么宽。R3 的这一条还点名了路由、委派、工具授权、用量与最终状态，而本次变更对它们一概没有覆盖 —— 它们属于 R3 尚未构建的调度与编排工作。在那些消费者存在之前就把记录加宽，等于为并不存在的消费者发明一套分类法，而[证据规则](../../../../packages/AGENTS.md)禁止这样做。

## Alternatives considered

**给 `RunAdmissionPolicy` 加一个审计 sink 端口。** 包最初的笔记否决了它，而这个否决依然成立：sink 参数增加的是一项类型系统并不强制的义务，调用方完全可以传入一个把一切丢弃的 sink。把记录放在结果里返回，使它们不可能收不到，这是更强的性质。持久化它们仍归调用方。

**为保险库看不到的那些阶段合成一条准入审计。** 这会让每一种拒绝都有非空的轨迹，并给出统一的「有什么东西被拒绝了」的记录。被否决是因为它凭空造出一个事件：没有任何凭据操作发生过，而一条声称发生过的记录，比一个诚实的空数组配上一个具名的拒绝阶段更糟。

**就让它作为一条已记录的限制留着。** 这正是这个包此前的做法，也正是这个缺陷得以在自己的审查中存活下来的原因。限制描述的是一个包不做什么；而这里是这个包收到了一条记录，然后把它丢掉了。
