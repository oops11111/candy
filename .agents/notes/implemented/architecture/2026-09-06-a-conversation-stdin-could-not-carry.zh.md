# Agent Note: stdin 承载不了的对话

Status: implemented

[English](2026-09-06-a-conversation-stdin-could-not-carry.md) | 中文

## Problem

`dsh-llm-claude-cli` 拒绝任何携带多于一条消息的请求，而这条拒绝正是把 Claude CLI 路由挡在智能体主循环之外的唯一原因——主循环每个请求都会带上历史。这条拒绝依据的是一次录制到的观察（两条消息的输入产出了两个 `result` 帧），以及一个在三处被当作事实陈述的假设：`--input-format stream-json`「只接受用户消息」。没有人真的喂给它一条 assistant 消息。

这很要紧，因为那个假设指向了一条修复路径。如果 CLI 会拒绝 assistant 消息，后来的维护者一试便知；如果它接受，那这条路由离服务主循环只差一处小改动。

## Decision

这条输入被实测了。一次 `claude` 2.1.263 的运行从 stdin 依次收到一条 user 消息、一条 assistant 消息和第二条 user 消息，该录制现已成为 `dsh-claude-cli-protocol` 中的 `injected-history.jsonl`。历史仍然被拒绝，但依据的是证据而不是假设。

这次运行显示的事实：

- **两个会话、两个终止帧。** 每条 user 消息各自开出自己的 `system`/`init`，并以自己的 `result` 结束。第一个轮次为一个唯一用途只是充当上下文的回合，计入了 3889 个输入 token 和 76 个输出 token。
- **那条 assistant 消息被接收后丢弃。** 没有任何一帧携带它的文本，也没有任何一帧报告它被拒绝。CLI 读了那一行，然后丢掉了它。
- **调用方会收到错误的答案。** `ClaudeCliFrameTranslator` 在第一个终止帧上定案——这是正确的，因为这条缝隙每条流只允许一个终止 chunk。重放该录制得到的是对话*第一条*消息的回复。而对最后一条消息的回复 `"Teal."`，才是调用方所要、所付费、却永远看不到的答案。

因此把历史摊平到这条输入上比丢掉它更糟。它回答的是另一个问题，代价是每个先前回合一次计费的模型调用，而这一切没有一处是有声的。

通往历史的剩余那条路是把对话渲染成提示词文本，也就是 [`packages/AGENTS.md`](../../../../packages/AGENTS.md) 要求提供依据、而本仓库并没有依据的那种转录格式。这里实测到的任何东西都无法提供这份依据：CLI 接受任意提示词文本，因此每一种候选格式都「能用」，它们之间的差别是模型输出质量，而 harness 里没有任何门禁会观察到它。

## Consequences

智能体主循环仍然无法使用这条路由，但其理由现在是一份带四个测试的录制，而不是一句话。伸手去碰 `--input-format stream-json` 的维护者，会在花掉一个回合之前先看到这次实测。

反向对照就是翻译器自己的闩锁：解开 `ClaudeCliFrameTranslator.translate` 的闩会让第四个测试失败，而其余十二个仍然通过，因此这个测试固定的是合并行为，而不只是夹具存在与否。

这份夹具是本包中第一份不是单轮的录制运行，因此它同时也是解码器跨越流中会话边界时行为的唯一覆盖：什么也不做，这是对的——第二个 `init` 帧不产出任何 chunk。

## Alternatives considered

**写出 CLI 自己的会话转录并 `--resume`。** CLI 会把一个会话以 JSONL 持久化在 `HOME` 之下，而一份录制到的转录是有依据的格式、而非发明。读过那份录制后此路被否决：`parentUuid` 链、`promptId`、thinking 块的签名，以及 `queue-operation`、`atis-latch`、`ai-title` 和 `last-prompt` 记录，无一有文档，且全都与版本绑定。伪造它与发明一种文本格式是同一种无声失败，只是面更大。它还需要会话持久化，而这次调用刻意禁用了它，好让一个租户的运行不在池里给下一个租户留下任何东西。

**把对 assistant 消息的拒绝做得更响。** 没有什么可以做得更响：请求早在 `stream()` 处、任何进程启动之前就已被拒绝，而 CLI 自身的沉默正是这份夹具所记录的东西。

**保持 README 原来的说法。** 「只接受用户消息」是一个关于校验的断言，而 CLI 根本不做校验。据此行事的维护者会预期一个错误，却得到一个错误的答案。
